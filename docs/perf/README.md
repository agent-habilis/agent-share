## Notes

- `native-synth-quic`: single-stream serial fill (`mount/bench.rs:493`) — a latency probe and a floor, not mount throughput
- `native-synth-quic`: the control leg — plain iroh QUIC over UDP, nothing forced and nothing cleared
- `native-synth-webrtc`: single-stream serial fill (`mount/bench.rs:493`) — a latency probe and a floor, not mount throughput
- `native-synth-webrtc`: QUIC inside a WebRTC data channel: bytes are encrypted twice, and `host/sender.rs:52` undoes GSO batching into one data-channel message per QUIC datagram
- `native-synth-relay`: single-stream serial fill (`mount/bench.rs:493`) — a latency probe and a floor, not mount throughput
- `native-synth-relay`: routed through a public iroh relay, so throughput is bounded by that shared path's bandwidth as well as its RTT — the high-RTT point, but not a controlled one
- `native-mount-cp`: a full read of one 256 MiB file through the OS NFS client
- `native-mount-cp`: mount options carry `rsize=131072` and no `readahead=` (`consume.rs:588-599`), so this is the depth-1 path finding #1 describes
- `native-mount-cp`: the default path: plain iroh QUIC over UDP, no WebRTC wrapper
