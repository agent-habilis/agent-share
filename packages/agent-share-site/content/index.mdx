    <h2 className="tile-title"><TerminalIcon /> Two commands</h2>
    <p>One machine serves a folder. It prints a ticket. The other machine mounts the folder with that ticket.</p>

```sh
# producer
agent-share serve ./notes

# consumer, on any other machine
agent-share <ticket> ~/mnt
```

  </div>
  <Cards.Card icon={<LazyIcon />} title="Lazy, ranged reads" href="/docs/concepts#lazy-reads">

  <Cards.Card icon={<LiveIcon />} title="Live" href="/docs/concepts#live-changes">
    <p>Edits, new files and deletions reach connected peers without a remount.</p>
  </Cards.Card>
  <Cards.Card icon={<DriveIcon />} title="The OS's own NFS client" href="/docs/concepts#the-nfs-bridge">
    <p>A loopback NFSv3 bridge. No FUSE, no kernel extension, no daemon.</p>
  </Cards.Card>
  <Cards.Card icon={<LockIcon />} title="Password-protected" href="/docs/commands#passwords">
